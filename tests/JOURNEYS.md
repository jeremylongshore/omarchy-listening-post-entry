# Acceptance journeys

1. Install on stock Omarchy and create the private state directory before first load.
2. Poll the 29 fixed sources with HTTPS, body, redirect, and time boundaries.
3. Parse releases, pricing, incidents, and engineering posts into separate lanes.
4. Float locally used providers first without opening their usage files.
5. Operate the queue by pointer, keyboard, and IPC; persist bounded read state.
6. Restart safely from malformed, empty, or absent state without exposing a credential or custom host.
7. Render all four lanes on isolated Buzz, reject QML warnings, and inspect the exact 1280x720 marketplace image before submission.
8. Pair a Perception device without placing its token in process arguments or public state.
9. Render the contract-v1 ranked field and five-item brief; source and Perception deep links remain HTTPS-only.
10. Keep last-good Perception data on offline, unauthorized, expired, oversized, and malformed responses without falling back to mixed local data.
11. Mark signals read from Omarchy and observe the same read state in the account snapshot; retry transient failures without blocking behind retired signals.
